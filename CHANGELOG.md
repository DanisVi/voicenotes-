# Changelog — VoiceNotes Pro

Все значимые изменения. Формат вдохновлён [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Added

- Чек-листы: клик по чекбоксу меняет статус прямо в заметке
- Уникальные id заметок и групп (UUID вместо метки времени)
- Защита от перебора PIN: 5 неверных попыток → пауза с ростом до 15 минут
- Мультивкладочность: изменения заметок синхронизируются между вкладками
- Тесты на чистые функции (парсер, слияние vault, timestamp) — node:test, 17 тестов
- Раздел «О приложении» (версия, лицензия, ссылка на исходники)
- Ctrl/Cmd+K — быстрый фокус в поиск с любого экрана
- Слияние бэкапов: выбор более новой версии заметки по дате
- Подтверждение PIN при создании vault (защита от опечатки)
- Markdown в заметках (marked + DOMPurify)

### Fixed

- Аудит безопасности: XSS в группах и VoiceModal, изоляция оверлеев при блокировке
- Починка тумблера автоблокировки
- Стабильность LockScreen: защита от параллельных submit, TypeError после успешного входа
- Корректный teardown голосового ввода (микрофон не «висит»)
- PWA-пути под /voicenotes-/: start_url/scope/icons, favicon, mobile-web-app-capable
- Контраст карточки «Защита активна» в тёмной теме
- Разрешён pinch-zoom
- Чистка мёртвого кода (11 файлов)

### Первые вехи

- Крипто-ядро, IndexedDB, auth
- LockScreen с PIN-точками
- MainScreen, группы, избранное
- Голосовой ввод и парсер команд
- Автоблокировка
- PWA (manifest, SW, иконки)
- Деплой через GitHub Actions
- Экспорт/импорт .vnp
- Тёмная тема auto/light/dark
- Подтверждение удаления
- Автофокус и управление с клавиатуры
- Адаптивный UI
- Единый экран Настроек
- Смена PIN с перешифровкой vault
- Ввод PIN с физической клавиатуры
- Поиск и фильтры
