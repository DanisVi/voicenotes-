# VoiceNotes Pro

Приватное приложение для заметок с голосовым вводом, Markdown и чек-листами.  
Заметки шифруются AES-256-GCM и хранятся только в браузере — без сервера, без облачной синхронизации.

**Live:** https://danisvi.github.io/voicenotes-/

---

## Статус

VoiceNotes Pro готов для личного использования.

- Данные шифруются локально в браузере.
- Восстановление vault без PIN невозможно.
- Проект находится в активной разработке: возможны изменения формата данных и поведения.
- Независимый аудит безопасности не проводился.

## ✨ Возможности

- 🔐 **Локальное шифрование** — AES-256-GCM, PBKDF2 (250k)
- 🎤 **Голосовой ввод** — Web Speech API, распознавание на русском, голосовые команды
- 📁 **Группы и избранное** — организация заметок с эмодзи-иконками
- 📝 **Markdown и чек-листы** — заголовки, списки, жирный, код, ссылки; кликабельные чекбоксы прямо в заметке
- 🔎 **Поиск и фильтры** — по тексту, группе, избранному, дате
- 💾 **Резервное копирование** — экспорт/импорт `.vnp` (Слить / Заменить)
- 🌓 **Темы** — auto / light / dark, anti-FOUC
- 📱 **PWA** — установка на домашний экран, офлайн-интерфейс

Подробнее о чек-листах, Markdown и горячих клавишах — в [USER-GUIDE.md](USER-GUIDE.md).

## 🔐 Безопасность и ограничения

- Заметки шифруются **локально в браузере**: AES-256-GCM.
- Ключ выводится из PIN через **PBKDF2, 250 000 итераций** (SHA-256).
- Данные хранятся в **IndexedDB** и не отправляются на сервер.
- PIN не хранится в открытом виде — только canary для проверки.

### Ограничения

- Приложение защищает данные **на устройстве**, но не защищает от вредоносных расширений браузера, скомпрометированного устройства или физического доступа.
- **Забытый PIN восстановить невозможно** — экспорт делайте заранее.
- GitHub Pages не позволяет задавать HTTP-заголовки CSP. Защита в глубину через meta-тег — в планах.
- PIN защищён от перебора: 5 неверных попыток → пауза с ростом до 15 минут.

## 🌐 Поддержка браузеров

| Функция | Chrome | Edge | Firefox | Safari |
|---|:---:|:---:|:---:|:---:|
| Заметки, Markdown, чек-листы, PWA | ✅ | ✅ | ✅ | ✅ |
| Голосовой ввод | ✅* | ✅* | ❌ | ⚠️** |

\* Требует доступа к микрофону; в Chrome/Edge распознавание идёт через серверы Google, поэтому нужно интернет-соединение.  
\*\* Safari 14.1+, работает нестабильно. Web Speech API в Firefox не реализован.

## 🛠 Стек

- **Frontend:** Vanilla JS (ES-модули), Vite 5
- **Стили:** Tailwind CSS 3.4
- **Крипто:** Web Crypto API (AES-256-GCM, PBKDF2)
- **Хранилище:** IndexedDB (зашифрованный vault + метаданные)
- **Голос:** Web Speech API
- **Сборка:** Vite → GitHub Pages (CI via Actions)
