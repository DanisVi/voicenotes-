# VoiceNotes Pro

Защищённое приложение для заметок с голосовым вводом, локальным AES-256 шифрованием и поддержкой PWA.

**Live:** https://danisvi.github.io/voicenotes-/

---

## ✨ Возможности

- 🔐 **Локальное шифрование** — AES-256-GCM, PBKDF2 (250k), canary-проверка пароля
- 🎤 **Голосовой ввод** — Web Speech API, распознавание на русском
- 🗣 **Голосовые команды** — «в группу X», «в избранное», «отмена»
- 📁 **Группы и избранное** — организация заметок с эмодзи-иконками
- 🌓 **Темы** — auto / light / dark, переключатель в Настройках, anti-FOUC
- 💾 **Резервное копирование** — `.vnp`, режимы Слить / Заменить
- ⏱ **Автоблокировка** — по таймауту бездействия
- 📱 **PWA** — установка на домашний экран, офлайн-режим (в разработке: splash, офлайн-страница)
- 🗑 **Удаление с подтверждением** — заметка и группа удаляются только после подтверждения; заметки удалённой группы остаются без группы
- ⚙️ **Единый экран Настроек** — тема, безопасность, данные в одном месте, группировка по разделам
- 🔐 **Смена PIN** — из Настроек, с подтверждением старого кода и перешифровкой vault
- 🔐 **Подтверждение PIN** — при создании vault код вводится дважды, защита от опечатки
- 🔎 **Поиск и фильтры** — по тексту (многословный), группе, избранному, дате (Сегодня / Вчера / 7 / 30 дней), с комбинированием и счётчиком активных
- 📝 **Markdown** — заголовки, списки, жирный, код, ссылки в заметках (marked + DOMPurify, безопасный рендер)
- ☑️ **Чек-листы** — список дел с кликабельными чекбоксами прямо в заметке (подробнее — ниже)

### ☑️ Как пользоваться чек-листами

Чек-лист — это список дел внутри заметки. Каждый пункт можно отметить выполненным одним кликом, не выходя из заметки.

**Создать чек-лист.** В тексте заметки напишите строку в формате `- [ ]` и текст пункта. Между скобкой и текстом — пробел:

```
- [ ] купить хлеб
- [ ] позвонить маме
- [ ] вынести мусор
```

Такой список отобразится с пустыми квадратиками. Отмеченный пункт выглядит как `- [x] купить хлеб` и появляется с галочкой.

**Отметить пункт.** Просто кликните по квадратику — он переключится на противоположное состояние (пустой ↔ галочка). Изменение сохраняется сразу, переживает блокировку и перезапуск приложения.

**Подсказки:**

- Вставляйте чек-лист в текст заметки при её создании (правка текста готовой заметки в приложении пока не поддерживается).
- Нумерованные списки (`1. [ ] пункт`) тоже работают как чек-листы.
- Отметка кликом правит сам текст заметки, поэтому пункт можно править как обычную строку.

### 📝 Шпаргалка Markdown

Заметки оформляются через Markdown: наберите текст по этим правилам — он красиво отобразится. Обычный текст без разметки показывается как есть.

**Текст и акценты**

| Что сделать | Как написать | Как выглядит |
| --- | --- | --- |
| Жирный | `**жирный**` | **жирный** |
| Курсив | `*курсив*` | *курсив* |
| Зачёркнутый | `~~зачёркнутый~~` | ~~зачёркнутый~~ |
| Код (фрагмент) | `` `код` `` | `код` |
| Перенос строки | одна новая строка | перенос включён по умолчанию |

**Блоки**

| Что сделать | Как написать |
| --- | --- |
| Заголовок 1-го уровня | `# Заголовок` |
| Заголовок меньшего уровня | `## Заголовок`, `### Заголовок` … до `######` |
| Маркированный список | `- пункт` (или `* пункт`) |
| Нумерованный список | `1. пункт` |
| Цитата | `> текст` |
| Код 여러 строк | обернуть в тройные обратные кавычки: <code>```</code> |
| Горизонтальный разделитель | `---` на отдельной строке |

**Ссылки**

`[текст ссылки](https://example.com)` — ведёт по адресу. Просто набранный адрес вида `https://example.com` тоже превращается в ссылку автоматически. Работают только адреса `http://`, `https://` и `mailto:` — остальное рендер отбрасывает.

**Чек-листы** — отдельная инструкция [выше](#-как-пользоваться-чек-листами).

> ⚠️ Картинки (`![описание](адрес)`) и таблицы в заметках **не поддерживаются** — разметка безопасного рендера их не пропускает.

### ⌨️ Управление с клавиатуры

**Экран блокировки:**

- `0–9` — ввод PIN
- `Backspace` / `Delete` — удалить последнюю цифру

**Заметки:**

- `Enter` — сохранить заметку
- `Shift+Enter` — перенос строки
- `Esc` — закрыть шторку (когда фокус в поле ввода)

## 🛠 Стек

- **Frontend:** Vanilla JS (ES-модули), Vite 5
- **Стили:** Tailwind CSS 3.4 + утилиты (ios-ink)
- **Крипто:** Web Crypto API (AES-256-GCM, PBKDF2)
- **Хранилище:** IndexedDB (зашифрованный vault + метаданные)
- **Голос:** Web Speech API (SpeechRecognition)
- **Сборка:** Vite → GitHub Pages (CI via Actions)
